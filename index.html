YOLO CAMPERVANS

Display installer

Put the Yolo power dashboard on your display in about two minutes. Nothing to download or install.

What you need

Only these exact boards are supported. Other boards or versions won't work.

  • A USB-C data cable (some cables only charge)
  • A computer with Chrome, Edge, Opera or Firefox (not Safari, not a phone)

1. Install

  1. Hold the BOOT button on the display, plug it into this computer, then let go.
  2. Click Install, choose the port that appears (often "USB JTAG/serial debug unit"), and confirm.
  3. Wait for "Installation complete" (1–2 minutes). Don't unplug during install.
  4. Unplug the display and plug it back in (without holding BOOT) to start it.

This browser can't install firmware. Use Chrome, Edge, Opera or Firefox on a computer.

This page must be opened over https.

No port showing? Use a USB-C cable that carries data (some only charge), plug straight into the computer, and make sure you held BOOT while plugging in.

2. See it working right away

After you plug it back in, the display starts in demo mode with sample numbers, so you know it works. Mount it and finish your build. No Cerbo GX needed yet.

3. Connect your Cerbo GX (when it's installed)

  1. On the Cerbo GX, go to Settings → Services and turn on MQTT on LAN.
  2. Hold the display's screen for 3 seconds. It shows Setup mode and a network name like YOLO-Setup-1A2B.
  3. On your phone, join that Wi-Fi network. A setup page opens (if not, browse to 192.168.4.1).
  4. Pick your van's Wi-Fi, enter the password and the Cerbo address (usually venus.local), then tap Save and connect.
  5. The display shows "LINKED" and your live numbers. Done.

Troubleshooting

  • "Looking for Cerbo" doesn't change: check MQTT on LAN is on, or enter the Cerbo's IP address instead of venus.local (hold the screen 3 s to change it).
  • "No Wi-Fi": check the Wi-Fi name and password in setup mode.
  • Start over: hold BOOT for 5 seconds while powering on. The display returns to demo mode.
  • Updates: come back to this page and click Install again.

Need help? Contact Yolo Campervans. Firmware is provided as-is for use with Yolo display kits.
