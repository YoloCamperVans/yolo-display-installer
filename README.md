# Yolo Campervans display installer

Web installer for the Yolo Campervans power dashboard on the Waveshare ESP32-S3-Touch-LCD-1.46 and ESP32-S3-Touch-LCD-2.8C.

**Open the installer:** https://yolocampervans.github.io/yolo-display-installer/

Use Chrome, Edge, Opera or Firefox on a computer. Hold the display's BOOT button while plugging it in, click Install, then unplug and plug it back in when it finishes.

Current firmware: 1.46 = 1.0.3, 2.8C = 1.0.0
